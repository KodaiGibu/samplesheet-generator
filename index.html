SampleSheet作成ツール（MiSeq i100 / NextSeq / MiSeq）

[Header] / [Reads]
[BCLConvert_Settings] / [Cloud_Settings]

OverrideCycles を空欄にすると R1:Y{Read1};I1:I{Index1};I2:I{Index2};R2:Y{Read2} を自動生成します。

Index（set 指定）
入力方法:
Index1 / i7
Index2 / i5
—

1つの set（例 set1-1-3）＝ 8連チューブ1本分の 8 index。 プルダウンでは 48 個の set（4セット × 12グループ）から選べます。終了 set に「（開始のみ）」を選ぶと 8 index だけになります。 手動入力に切り替えると、12 のような番号だけの省略指定も使えます。
Index2 を自動入力が ON のとき、Index1 に set1-1-1 を選ぶと Index2 に set1-2-1 が自動で入ります（入力後の手修正も可能）。 セットをまたぐ範囲（set1-1-10 〜 set2-1-3）や複数範囲の併記にも対応します。
