SampleSheet作成ツール（GenerateFASTQ）

[Header] / [Settings]

日付は YYYY/M/D 形式（2026-08-18 のような入力も自動変換します）。

Index（set 指定）
Index1 / i7
Index2 / i5
—

1つの set（例 set1-1-3）＝ 8連チューブ1本分の 8 index。 終了 set を空欄にすると開始 set のみ（8 index）、12 のように番号だけでも指定できます。
複数セットの指定: set1-1-10 〜 set2-1-3 のようにセットをまたいだ範囲を直接指定できます （set1-1-12 の次は set2-1-1 として連続展開）。連続しないセットを組み合わせる場合は「＋ 範囲を追加」で行を増やしてください。

[Data]（リストを貼り付け）
Sample_ID（1行1件）
Sample_Name（空欄なら Sample_ID を反映）
Description（1行1件）
サンプル名の末尾に文字列を追加

左側の行番号を参照して範囲を指定してください。「付与前に戻す」は、 この列に対して 最初に追加を行う前の状態 にまとめて戻します（複数回追加していても一度で戻ります）。
